# Northline Field Hockey Website

This project is a two-page field hockey website with an editorial landing page and an interactive coaching toolkit.

## Pages

- **index.html**: One-page editorial landing with quick stats, playing philosophy, and contact details.
- **skills.html**: Interactive Skills & Drills toolkit with filtering, drill details, a practice timer, and a session builder.

## Deploy on GitHub Pages

1. Push the repository to GitHub.
2. In your repository settings, open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch (usually `main`) and set the root folder to `/`.
5. Save. Your site will be available at the provided GitHub Pages URL.

All assets use relative paths, so the site works directly on GitHub Pages.
